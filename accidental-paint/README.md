# What a test server painted by mistake (2026-10-17)

While checking the lantern light, a test server in the cloud started with the
project's Gemini key and painted on its own at start-up, as the game does when
art is missing. This is everything that came back, for looking at. Nothing
here is used by the game.

Paid: 10 pictures (about $0.39), 7 music clips ($0.28) and 1 Veo walk clip
(about $0.40, for Ilya walking towards us). The walk clip never came back: the
server was stopped before it was collected, so there is no file for it.
